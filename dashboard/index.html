🔑 POSTECH AI API 설정

posicube-services/llm-agent-api 의 a1~a3 단일 호출 API 규격을 사용합니다 — 엔드포인트에 {"message": "...", "stream": false}를 POST하면 {"message": "..."}로 응답이 옵니다. 헤더는 x-api-key가 필수이며, Claude/Gemini는 Authorization 헤더에도 같은 키를 함께 보냅니다. 키는 브라우저(LocalStorage)에만 저장되며 이 페이지 외 다른 곳으로 전송되지 않습니다.

⚠️ "Failed to fetch" 오류가 나면 대부분 CORS 차단입니다 (이 API는 서버용으로 만들어져 브라우저 직접 호출을 막아둘 수 있음). dashboard/cors-proxy/README.md의 프록시를 세우고 엔드포인트를 프록시 주소로 바꿔보세요.
